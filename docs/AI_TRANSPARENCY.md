# 🤖 AI 투명성 리포트 (AI Transparency Report)

> **프로젝트**: AlgoRhythm — 규칙 및 전략 기반 인력 운영 최적화 지능형 스케줄링 웹 플랫폼
> **팀**: 2026 이화여자대학교 캡스톤디자인과창업프로젝트 · Team 알고리듬
> **문서 목적**: 본 프로젝트의 (1) 개발 과정과 (2) 제품 동작에 사용된 AI를 투명하게 공개하고, 사람과 AI의 역할·검증·한계를 명확히 한다.
> **최종 수정일**: 2026-06-03

## 1. 요약 (TL;DR)

AlgoRhythm은 두 가지 맥락에서 AI를 사용합니다.

1. **제품 런타임 AI** — 관리자가 자연어로 입력한 근무 요구사항을 제약조건으로 변환하는 데 **OpenAI API**를 사용합니다.
2. **개발 보조 AI** — 코드 작성·디버깅·문서화 과정에서 생성형 AI 도구를 보조적으로 사용했습니다.

모든 AI 산출물은 팀원의 검토·수정을 거쳐 반영했으며, 최종 결과물에 대한 책임은 팀에 있습니다.

---

## 2. 제품에 내장된 AI (Runtime AI)

| 항목 | 내용 |
|---|---|
| 사용 모델/서비스 | OpenAI API (모델: gpt-4o-mini ) |
| 사용 목적 | 자연어로 입력된 근무자 요구사항을 구조화된 제약조건으로 파싱, 결원 시 대체 인력 매칭 추천 보조 |
| 입력 데이터 | 관리자가 입력한 요구사항 텍스트. 실명/연락처 등 개인정보 |
| 출력 사용 방식 | LLM 출력은 **최종 결정이 아니라 후보/초안**으로 사용되며, 하드 제약조건 검증 로직과 관리자 승인을 거쳐야 시간표에 반영됨 |
| 의사결정 권한 | 최종 배정 결정은 **관리자(사람)** 가 수행 (AI는 추천만) |
| 호출 시점 | 진행 예정  |


---

## 3. 개발 과정에서 사용한 AI (Development-time AI)

생성형 AI 도구를 다음 작업에 **보조 수단**으로 사용했습니다. (실제 사용한 도구·범위에 맞게 수정)

| 도구 | 사용 영역 | 사람의 역할 (검증/수정) |
|---|---|---|
| Codex / Gemini / Claude / GitHub Copilot | 보일러플레이트 코드 생성, 디버깅 보조 | 모든 코드는 팀원이 리뷰 후 커밋, PR 단계에서 상호 검토 |
| Claude | README·문서 초안 작성 및 교정 | 사실관계·링크·기술 내용은 팀원이 직접 검증 |
| Gemini/ Claude / ChatGPT | 아이디어·설계 브레인스토밍 | 채택 여부는 팀 논의로 결정 |

**사용하지 않은 영역**: 핵심 스케줄링 알고리즘은 팀이 직접 설계·구현

## 4. 데이터 및 프라이버시

- 본 프로젝트는 **실제 학교의 개인정보(교사 실명·연락처 등)를 사용하지 않으며**, 데모/테스트는 가상 데이터로 수행합니다. 
- OpenAI API로 전송되는 데이터의 범위: 자연어 텍스트, 기타 (이후 추가 예정)
- API Key, DB·Redis·SMTP 자격증명 등 민감정보는 **환경변수로 분리**하여 저장소에 커밋하지 않습니다.
- 외부 AI 서비스로 전송된 데이터의 보관/학습 정책은 해당 제공자(OpenAI)의 정책을 따릅니다.

---

## 5. 한계 및 책임 (Limitations & Accountability)

- 생성형 AI는 사실과 다른 내용(환각)을 만들 수 있으므로, **모든 AI 산출물은 팀원 검토를 전제**로 사용했습니다.
- LLM 기반 제약조건 파싱은 입력 표현에 따라 오해석 가능성이 있어, **하드 제약조건 검증 로직과 관리자 승인**이라는 안전장치를 둡니다.
- 본 문서에 기재된 내용과 실제 구현/배포가 불일치할 경우, **실제 구현을 기준**으로 하며 문서를 갱신합니다.
- 최종 산출물의 정확성·적법성에 대한 책임은 Team 알고리듬에 있습니다.
