## 11차 정기회의
**📅 2026.10.06 (화)**

#### 안건
- 타 팀 중간 발표 참관

- 중간 발표 대본 최종 수정 (Gmail SMTP 관련)

#### 개발 진행 사항
**Backend**
- FE에 API 명세서(Swagger) 전달
  → [AlgoRhythm Swagger](https://ourschoolschedule.github.io/AlgoRhythm-swagger/)
- Backend–Frontend 연동 가이드 전달 (시나리오별 API 연결, Request / Response DTO)
- DB 접속 정보 제공 (Read 권한) 및 더미 데이터 작성 · 제공
- 배포 및 인프라 구성

| 항목 | 내용 |
| :--- | :--- |
| 배포 | Railway (Spring Server, Redis, MySQL) |
| 메일 | Resend HTTP API |
| DNS | Gabia |
| AI | OpenAI API 키 연결 |

**Frontend**
- API 명세서 기반으로 BE와 협의하며 개발 진행
