# FE12 상세 화면 검수

기준 브랜치는 `fe/develop`, 변경 전 기준은 FE11 `8d23e6c`다. 프로덕션 빌드를 로컬에서 띄운 Chromium에서 학교 540001·학기 547001의 모의 응답을 사용했다. 시간표 캡처는 저장소의 School42 `example_week.csv`와 `teacher_roster.csv`로 만들었다. 화면 날짜는 한국 시간 2026-11-25로 고정했다.

## 역할별 메뉴

표에서 ‘열림’은 해당 역할로 메뉴를 선택해 본문의 제목과 현재 메뉴를 확인했다는 뜻이다. 각 역할을 1440px, 768px, 390px에서 라이트·다크·시스템 모드로 점검했다. 시스템 모드는 브라우저의 색상 설정을 변경해 실제 테마 전환도 확인했다.

| 메뉴 | 재직 관리자 | 재직 교사 | 확인한 화면 요소 |
| --- | --- | --- | --- |
| 업무 홈 | 열림 | 열림 | 학교 확인, 역할별 메뉴와 상세 화면 진입 |
| 시간표 | 열림 | 열림 | 주 이동, 주간표, 오늘 열, 선택 셀과 수업 상세 |
| 할 일 | 열림 | 열림 | 날짜, 범위 선택, 업무 상태별 목록 |
| 보결·교환 업무 | 열림 | 열림 | 날짜 수업 선택, 역할별 신청·응답·승인 영역 |
| 요청 내역 | 열림 | 열림 | 기간·상태·종류 필터와 결과 목록 |
| 시간표 생성 | 열림 | 메뉴 숨김 | 시수표 검증, 후보 선택과 게시 |
| 과목·수업 관리 | 열림 | 메뉴 숨김 | 입력 폼, CSV 진입점, 등록 과목 목록 |
| 관리자 도구 | 열림 | 메뉴 숨김 | 관리 탭, 교사 명부와 표 스크롤 |

## 조작 및 회귀 검증

- 라이트·다크에서 오늘 열의 수업 셀에 키보드로 포커스를 두고 Enter로 상세를 열었다. 오늘 표식과 선택 테두리가 동시에 존재하며 Esc로 닫으면 같은 셀로 돌아왔다.
- 관리자 탭에서 방향키와 Home 키로 선택과 포커스가 같이 바뀌었다. 390px에서 시간표를 가로로 스크롤하고 교사 명부의 스크롤 영역에서는 방향키로 오른쪽 열을 확인했다. 본문 전체의 가로 넘침은 없었다.
- 시수표 업로드의 422 응답에서 C2와 오류 코드 `INVALID_HOURS`를 확인했다. 재검증 후 202 접수와 READY를 거쳐 후보를 선택하고, 게시 409에서는 서버 버전 1과 선택 해제·게시 버튼 비활성화를 확인했다. 게시 요청은 한 번이었다.
- 별도의 수락된 보결·교환 신청을 각각 승인해 완료 상태를 확인했다. 두 승인 요청 모두 멱등 키를 전송했다. 동일 승인 재전송은 기존 Vitest 회귀 검사에서 확인했다.

실제 계정과 운영 DB를 사용하는 종단간 검증, Vercel 공개 배포는 이 기록의 검증 범위 밖이다.
